Vouti – tietosuojaseloste

Kenen tietoja

Vouti on yksityinen, yhden käyttäjän apuohjelma. Se käsittelee vain omistajansa omien sähköpostitilien tietoja.

Mitä tietoja käytetään

Gmail-rajapintaa käytetään pelkällä lukuoikeudella (gmail.readonly). Luettavia tietoja ovat viestin lähettäjä, aihe, päiväys ja lyhyt katkelma. Koko viesti tai liite luetaan vain omistajan erillisestä pyynnöstä.

Mihin tietoja käytetään ja kenelle ne välitetään

Tietoja käytetään vain omistajan omiin yhteenvetoihin ja hakuihin. Yhteenvedot laaditaan ulkoisen tekoälypalvelun avulla, jolle välitetään vain yhteenvetoon tarvittava teksti. Tietoja ei myydä, ei käytetä mainontaan eikä luovuteta muille.

Suojaus ja säilytys

Kirjautumistiedot säilytetään salattuina. Viestejä ei tallenneta erilliseen tietokantaan.

Oikeuksien peruminen

Luvan voi perua milloin tahansa Google-tilin asetuksista: myaccount.google.com/permissions.

Googlen käyttäjätietojen käytäntö

Google-rajapinnoista saatujen tietojen käyttö noudattaa Google API Services User Data Policy -käytäntöä, myös sen Limited Use -vaatimuksia.

In English

Vouti is a private, single-user tool that reads only its owner's own email. It uses the Gmail API with read-only access (gmail.readonly) to read sender, subject, date and a short snippet; full messages or attachments only on the owner's explicit request. Data is used solely for the owner's own summaries and searches, prepared with an external AI service that receives only the text needed. Data is never sold, used for advertising or shared with anyone else. Sign-in credentials are stored encrypted; messages are not stored in any database. Access can be revoked at any time at myaccount.google.com/permissions. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
